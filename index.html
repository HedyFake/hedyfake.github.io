03 / RESEARCH LOOP

PIPELINE

Jalur riset yang dimulai dari batas yang jelas dan berakhir pada reporting yang bisa direproduksi.

01
RECON

Collect the visible attack surface and inventory the target.

02
SCOPE

Authorization, allowlist, excluded paths, and testing rules.

03
DISCOVER

Enumerate content, parameters, services, and behaviors.

04
ANALYZE

Normalize observations and use AI for triage context.

05
EVIDENCE

Attach request, response, observation, confidence, and notes.

06
REPORT

Turn validated findings into responsible documentation.

01 // SCOPE FIRST

Target → Authorization → Scope → Rules → Testing

No scope means no active test. Allowlist dan batasan menjaga workflow tetap terkendali.

02 // EVIDENCE FIRST

Finding tanpa evidence = sinyal

Sinyal perlu divalidasi sebelum diperlakukan sebagai finding yang layak dilaporkan.

03 // REPRODUCIBILITY

Target → Request → Response → Observation → Evidence

Jejak teknis dibuat agar proses dan temuan dapat ditelusuri kembali.

04 // FAIL CLOSED

Scope tidak jelas = STOP

Workflow berhenti daripada memperluas target secara tidak sengaja.

05 // HUMAN REVIEW

Automation bantu, manusia memvalidasi

AI membantu konteks dan triage; validitas finding tetap membutuhkan pemeriksaan manusia.

05 / AI + SECURITY

WORKFLOW

AI diposisikan sebagai layer analisis dan triage: data mentah dinormalisasi, evidence dipertahankan, konteks dibantu AI, lalu manusia memvalidasi.

COLLECTION

Raw findings, tool output, request/response context, target inventory, dan artefak relevan dikumpulkan tanpa mengaburkan provenance.

NORMALIZATION

Output heterogen dipetakan ke struktur konsisten sehingga target, endpoint, severity, confidence, dan evidence dapat dibandingkan.

AI ANALYSIS

AI membantu membaca konteks, menghubungkan finding dengan fingerprint, menyorot false-positive risk, dan menyusun prioritas investigasi.

HUMAN VALIDATION

Evidence diperiksa manusia sebelum finding diperlakukan sebagai hasil yang sah. Scope tetap menjadi batas utama.

REPORT

Temuan tervalidasi dirakit menjadi laporan yang dapat dibaca, direproduksi, dan dipakai untuk triage atau remediation.
